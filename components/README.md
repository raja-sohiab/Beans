# Functional Components

Components describe purposes, not reusable prose. Never assemble email text by concatenating components.

Each component must define:

```yaml
id:
purpose:
required_evidence:
incompatible_evidence:
compatible_strategies:
allowed_positions:
```

Initial categories: commercial observation, customer need, outreach action, interested-response handoff, CTA intent, P.S. intent, Email 2 continuation, Email 3 angle.
